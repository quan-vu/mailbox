# MailBox visual references

These 5 PNGs are generated reference mockups from the prior UI design session. They are provided specifically so coding agents have the exact visual target in this repository.

1. `01-unified-inbox.png` — 3-column inbox and read pane.
2. `02-connect-account.png` — provider selection, autoconfig, IMAP/SMTP form.
3. `03-thread.png` — conversation reading and attachments.
4. `04-compose.png` — rich composer with recipients, signature and templates.
5. `05-settings.png` — accounts, status, quota and preferences.

**Important**: Text/names/dates/providers/quotas inside these mockups are illustrative. Do not hard-code fictional “connected” health in production. The first visual implementation uses mock data and must retain demo indication.

For reproduction: compare at a common 1440px viewport and document actual screenshots + visual differences. Keep design tokens, not pixel-perfect text content copied from generated labels where those labels are wrong.
