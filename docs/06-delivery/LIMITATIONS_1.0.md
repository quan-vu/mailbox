# Desktop 1.0 — mocked and limited items

Owner decision (2026-11-14): build everything that can be built for real. Where an outside
dependency blocks a real implementation, ship a mock, and record it here. A mock must be
labelled as a mock in the UI and must never be reported as working.

Rules for every entry:

- The UI shows a visible "mock / chưa hoạt động thật" label on the control or screen.
- The mock sends nothing, stores no credential, and contacts no server.
- TRACKING marks the task `MOCK`, never `DONE`.
- The entry names what is needed to make it real.
